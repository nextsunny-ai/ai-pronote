# Mac 빠른 시작

1. ZIP을 `문서/AI PRONOTE` 같은 로컬 폴더에 완전히 풉니다.
2. Finder에서 `mac/1_FIRST_SETUP.command`를 Control-클릭 → 열기 합니다.
3. `mac/2_AI_LOGIN.command`에서 Claude, Gemini 또는 ChatGPT/Codex에 로그인합니다.
4. `mac/3_START_AI_PRONOTE.command`를 열고 앱 설정에서 로그인한 AI를 선택합니다.

macOS가 막으면 터미널에서 앱 폴더로 이동해 `chmod +x mac/*.command`를 한 번 실행합니다. 마이크·카메라 권한은 시스템 설정 → 개인정보 보호 및 보안에서 브라우저에 허용합니다.

회의 시작 전에 음성만 녹음하거나 `카메라 영상 함께 녹화`를 켤 수 있습니다. 영상 모드에서도 음성을 별도로 받아쓰기해 같은 회의의 AI 회의록을 만듭니다. 영상은 라이브러리에 로컬 저장됩니다.

Gemini는 Google 계정 종류와 현재 CLI 이용 정책에 따라 로그인이 거절될 수 있습니다. 이때는 Claude 또는 ChatGPT/Codex를 선택하세요.
