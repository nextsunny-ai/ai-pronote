# AI PRONOTE v1.5

현장 회의를 녹음하고, 받아쓰기와 AI 회의록을 만드는 Mac·Windows용 비공개 베타입니다.

## 핵심 사용 방식

- 음성만 녹음
- 카메라 영상과 음성을 함께 녹화 — 칠판·회의실 기록
- 녹음 없이 키보드 노트·펜 필기만 사용
- 기존 MP3, WAV, M4A, WEBM, OGG, FLAC, MP4 가져오기
- Claude, Gemini, ChatGPT/Codex CLI 로그인 선택

영상 모드에서도 음성 트랙을 별도로 처리하므로 받아쓰기와 AI 회의록이 생성됩니다. 영상과 회의 데이터는 기본적으로 사용자 컴퓨터의 `data_v15`에 보관됩니다.

## 비공개 베타 주의사항

- 코드 서명 전 시험판이므로 운영체제의 보안 경고가 나타날 수 있습니다.
- 실제 회의 전에 참석자에게 녹음·녹화와 외부 AI 처리 사실을 알리고 동의를 받으세요.
- Gemini 이용 가능 여부는 Google 계정과 Gemini CLI 정책에 따라 달라질 수 있습니다.
- 로그인 자격정보는 앱이 복사하거나 저장하지 않습니다.
