# Security policy

## Supported release

AI PRONOTE RC25 is a private external beta. It is unsigned and not approved for unrestricted public deployment. Security fixes are applied only to the latest published beta release.

## Reporting a vulnerability

Do not create a public GitHub issue for a suspected security vulnerability, exposed credential, or personal data incident. Use the private contact provided with the beta invitation. A dedicated public security contact is not yet assigned and must be established before formal release.

Include only the app version, operating system, reproduction steps using synthetic data, and expected impact. Do not send real meeting recordings, transcripts, participant information, passwords, API keys, tokens, cookies, or authentication screenshots.

Do not access, alter, download, or delete another person's data while testing. Do not perform denial-of-service testing, social engineering, physical attacks, or automated large-scale scanning.

## Response targets for the private beta

- Acknowledge receipt within two business days.
- Provide an initial severity assessment within five business days.
- For high-risk issues, decide on temporary mitigation or release withdrawal within seven days.

These are beta response targets, not a service-level agreement. Formal-release targets and the responsible security contact must be approved before launch.
