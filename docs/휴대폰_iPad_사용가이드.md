# AI PRONOTE 휴대폰·iPad 사용 가이드

AI PRONOTE의 휴대기기 화면은 PC에서 실행되는 설치본에 같은 Wi-Fi로 안전하게 연결해 사용합니다. PC를 켜 둔 상태에서 iPad·휴대폰을 회의용 리모컨, 녹음기, 필기판처럼 사용할 수 있습니다.

## 처음 연결

1. PC와 휴대폰 또는 iPad를 같은 Wi-Fi에 연결합니다.
2. PC에서 `iPad·휴대폰 연결`을 시작합니다.
3. 기기 카메라로 PC의 QR을 읽거나 표시된 HTTPS 주소를 Safari·Chrome에서 엽니다.
4. PC에 표시된 일회용 연결 코드를 입력합니다.
5. 첫 연결 뒤 브라우저 메뉴에서 `홈 화면에 추가`를 선택하면 노트 모양 AI PRONOTE 아이콘으로 바로 열 수 있습니다.

`localhost`는 휴대기기 자신을 뜻하므로 사용하지 않습니다. PC에 표시된 `https://192.168...:8796` 형태의 주소를 사용합니다.

## 휴대폰에서 권장하는 사용법

- 이동 중 음성 회의: 홈의 `녹음 시작` → `음성 녹음`을 선택합니다.
- 짧은 아이디어: `필기만 시작` → 텍스트 노트에 제목과 핵심 문장을 기록합니다.
- 회의 중 빠른 메모: 녹음은 계속 두고 키워드·결정·담당자만 짧게 적습니다.
- 결과 확인: `작업함`에서 처리 상태를 보고 `라이브러리`에서 받아쓰기와 회의록을 엽니다.
- 긴 문서 편집·여러 파일 내보내기·세밀한 펜 그림은 PC 또는 iPad가 더 편합니다.

휴대폰 세로 화면에서는 왼쪽 위 `☰`로 메뉴를 열고, 항목을 선택하면 메뉴가 자동으로 닫힙니다. 필기 도구줄은 좌우로 밀어 숨은 도구를 찾습니다.

## iPad에서 권장하는 사용법

- 세로 화면: 녹음 제어, 텍스트 메모, 결과 확인에 적합합니다.
- 가로 화면: 긴 회의록 검토와 키보드 입력에 적합합니다.
- 펜 필기: `필기만 시작` → `필기` → `Pencil 전용`을 켜면 손가락 터치는 필기로 남지 않습니다.
- 전체 화면: 노트의 `메뉴 숨기기`를 누르면 작성 공간을 넓게 쓰고, 왼쪽 위 `메뉴`로 되돌립니다.
- 칠판 기록: `영상 녹화`를 선택하고 후면 카메라가 칠판을 향하도록 고정한 뒤 10초 시험 녹화를 확인합니다.

## AI 연결

녹음·영상·기본 받아쓰기·필기는 로그인 없이 사용할 수 있습니다. AI 회의록·정확도 향상·에이전트 기능이 필요할 때만 연결합니다.

- iPad·휴대폰의 `설정 · 어드민`에서 Claude 상태를 확인합니다.
- `Google로 로그인`을 누르면 Safari 또는 Chrome에서 Claude 공식 로그인 페이지가 열립니다.
- 로그인 후 표시된 일회용 인증 코드를 AI PRONOTE에 붙여넣습니다.
- ChatGPT/Codex와 Gemini 공식 API 연결은 PC 설정에서 먼저 완료한 뒤 휴대기기에서 선택합니다.

## 회의가 다시 이어질 때

받아쓰기나 회의록이 생성 중이어도 결과 화면의 `회의 이어 녹음`을 누르면 같은 회의에 새 구간을 추가할 수 있습니다. 먼저 끝난 구간의 처리는 작업함에서 계속됩니다.

## 연결이 안 될 때

1. PC와 휴대기기가 같은 Wi-Fi인지 확인합니다.
2. PC의 연결 창이 계속 열려 있는지 확인합니다.
3. 이전 연결 코드가 아니라 새로 표시된 코드를 사용합니다.
4. `localhost 연결 거부`가 보이면 뒤로 돌아가 PC가 표시한 HTTPS 주소를 다시 엽니다.
5. 카메라·마이크가 켜지지 않으면 브라우저 주소창의 사이트 권한을 확인하고 10초 시험 녹화를 다시 합니다.
