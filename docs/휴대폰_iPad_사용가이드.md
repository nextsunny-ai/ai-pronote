# AI PRONOTE 1.0.10 휴대폰·iPad 사용 가이드

현재 외부 테스트의 휴대기기 화면은 Windows PC에서 실행되는 AI PRONOTE에 같은 Wi-Fi로 연결하는 동반형입니다. PC가 꺼져 있거나 다른 네트워크에 있으면 열리지 않습니다.

## 처음 연결

1. PC와 iPad·휴대폰을 같은 Wi-Fi에 연결합니다.
2. PC AI PRONOTE에서 `설정` → `iPad·휴대폰 연결`을 엽니다.
3. 화면의 큰 QR을 카메라로 읽거나 표시된 HTTPS 주소를 Safari·Chrome에서 엽니다.
4. PC에 표시된 6자리 일회용 연결 코드를 입력합니다.
5. 인증서 안내가 나오면 테스트 안내의 기기별 절차를 완료합니다.
6. 연결 후 브라우저의 `홈 화면에 추가`를 선택하면 노트+마이크 아이콘으로 열 수 있습니다.

`localhost`나 `127.0.0.1`은 휴대기기 자신을 뜻하므로 사용하지 않습니다. PC가 표시한 `https://192.168...:8796` 주소만 사용하세요. 연결 코드는 한 번 사용하면 폐기됩니다.

## 노트

- PC·iPad 가로 화면은 상단 두 줄 도구막대를 사용합니다.
- 휴대폰은 자주 쓰는 도구만 두 줄로 표시하며, 올가미·포스트잇·도형·사진·페이지·용지·분할·내보내기는 `···` 더보기에 있습니다.
- 텍스트 도구를 선택하고 캔버스를 누르면 그 위치에 입력 상자가 생깁니다.
- Apple Pencil은 펜 입력, 손가락은 기본적으로 화면 이동에 사용합니다. 손가락 필기가 필요하면 더보기에서 켭니다.
- 페이지 설정에서 화면 맞춤·A4·B5·Letter·정사각형, 세로·가로, 무지·점선·모눈·줄노트·원고지를 선택할 수 있습니다.

## 회의 녹음과 영상

회의 녹음 화면을 열어도 자동으로 녹음되지 않습니다. 음성 또는 카메라 영상을 선택하고 `녹음 시작`을 눌러야 시작합니다. 종료 직후에는 저장 중 상태가 표시되며 완료될 때까지 버튼을 다시 누를 수 없습니다.

Safari·Chrome에서 마이크 또는 카메라 권한을 요청하면 사용 목적을 확인한 뒤 허용하세요. 중요한 회의 전에는 10초 시험 녹음과 재생을 먼저 확인하세요.

## 받아쓰기와 회의록

외부 녹음·영상은 `받아쓰기`에서 선택합니다. 작업 진행률과 오류·재시도는 `작업 기록`에서 확인합니다. 완료된 회의록은 녹음 화면을 다시 열지 않아도 `회의록`과 `작업 기록`에서 열고 수정·저장할 수 있습니다.

## 화면이 겹치거나 잘릴 때

1. 브라우저 페이지 확대를 100%로 되돌립니다.
2. 홈 화면 아이콘으로 다시 엽니다.
3. iPad의 가로·세로를 한 번 전환합니다.
4. 여전히 잘리면 화면 캡처와 기기 모델·OS 버전을 테스트 담당자에게 보냅니다.

## 연결이 안 될 때

1. PC 앱과 모바일 연결 화면이 계속 실행 중인지 확인합니다.
2. 두 기기가 같은 Wi-Fi인지 확인합니다.
3. 새 연결 코드를 발급받습니다.
4. 방화벽 안내가 나오면 개인 네트워크에서만 AI PRONOTE를 허용합니다.
5. 공용 Wi-Fi·회사 게스트망처럼 기기 간 통신을 막는 네트워크에서는 연결되지 않을 수 있습니다.

## 개인정보

테스트 계정별 녹음·영상·받아쓰기·회의록·노트·AI 대화가 분리되어야 합니다. 다른 사람의 항목이 보이면 즉시 사용을 멈추고 화면과 시각만 보고하세요. 실제 회의 내용이나 원본 파일을 임의로 전달하지 마세요.
