# AI PRONOTE 1.0 휴대폰·iPad 사용 가이드

현재 iPad·휴대폰 검토본은 Windows PC에서 실행 중인 AI PRONOTE에 같은 네트워크로 접속하는 브라우저 동반 사용 방식입니다. 네이티브 iPad 앱이나 App Store 출시본으로 안내하지 않습니다.

## 현재 제공 상태

- Windows RC51에는 휴대기기 클라우드 동기화가 포함되지 않습니다.
- QR·연결 코드·`홈 화면에 추가` 방식은 내부·비공개 베타용 동반 접속입니다. PC가 켜져 있고 같은 네트워크에 연결돼야 합니다.
- iPhone·Android판은 별도 실기기 검증 전까지 지원 대상으로 표시하지 않습니다.

## iPad 최종 후보에서 확인할 사용법

1. Windows AI PRONOTE의 iPad 동반 접속을 실행하고 표시된 QR 주소를 Safari로 엽니다.
2. 앱 계정으로 로그인하거나, 로그인 전 이 기기 저장 범위에서 기능을 살펴봅니다.
3. `노트`를 누르면 새 노트가 바로 열리고 `회의 녹음`을 누르면 녹음 화면이 바로 열리는지 확인합니다.
4. 노트에서 Apple Pencil 필기와 키보드 텍스트를 전환하고 자동저장·재실행 복구를 확인합니다.
5. 회의가 끝나면 `회의 기록`에서 녹음·받아쓰기·회의록을 확인합니다.
6. 필요하면 Safari 공유 메뉴에서 홈 화면에 추가합니다. 이 아이콘은 네이티브 앱이 아니라 현재 PC의 동반 접속을 여는 바로가기입니다.
7. 계정 동기화는 운영 RLS와 서로 다른 실제 계정 A/B 차단 검증 뒤에만 켭니다.

## iPad 권장 화면

- 세로: 녹음 제어, 짧은 메모, 결과 확인.
- 가로: 자료와 노트 분할, 긴 회의록 검토, 키보드 입력.
- 필기: 펜·형광펜·지우개·올가미·도형·사진·포스트잇·용지/배경.
- 자료: 사진·PDF를 열어 노트와 좌우 또는 위아래로 분할.
- 내보내기: 지원 형식과 저장 위치를 선택하고 실제 파일이 열리는지 확인.

## AI 연결

앱 계정은 내 자료를 구분하는 계정이고 AI 연결은 회의록·정확도 향상·AI 비서에 사용하는 별도 설정입니다. Claude·ChatGPT/Codex 중 사용 가능으로 표시된 제공자 하나를 선택할 수 있습니다. Gemini는 공식 API 키 연결만 지원하며 계정 로그인 방식으로 표시하지 않습니다.
