# AI PRONOTE RC31 외부 베타 FAQ·지원 안내

이 문서는 코드 서명 전 비공개 베타 RC31 기준입니다. 실제 회의 전에는 5분 이하의 비민감 자료로 먼저 시험하세요.

## 설치와 실행

### 어떤 컴퓨터에서 사용할 수 있나요?

- Mac: macOS 12 이상, Apple Silicon·Intel, Python 3.10~3.12
- Windows: Windows 10/11 64비트, Python 3.10~3.12 64비트
- 최신 Chrome 또는 Edge를 권장합니다. Mac에서는 기본 브라우저에서도 열리지만, 카메라·마이크 권한이 잘 작동하지 않으면 Chrome에서 다시 시험하세요.

### 운영체제에서 경고가 나타납니다.

RC31은 코드 서명 전 시험판입니다.

- Mac: ZIP을 완전히 푼 뒤 `mac/1_FIRST_SETUP.command` 또는 `mac/AI PRONOTE.app`을 Control-클릭하고 `열기`를 선택합니다.
- Windows: 출처를 확인한 뒤 Windows 보호 화면에서 `추가 정보`를 선택해 실행합니다.

공유받은 ZIP의 파일명과 SHA-256 값이 공식 다운로드 페이지와 다르면 실행하지 마세요.

### Python이 없다고 나옵니다.

Python 3.10~3.12를 설치한 뒤 첫 설정 파일을 다시 실행하세요. Python 3.13 이상만 설치되어 있다면 3.12를 함께 설치하는 편이 안전합니다.

### 프로그램을 눌렀는데 바로 열리지 않습니다.

처음 실행은 필요한 구성요소를 준비하느라 시간이 걸릴 수 있습니다. 같은 파일을 연속으로 누르지 말고 최대 45초 기다린 뒤 한 번만 다시 실행하세요.

## AI 연결

### Claude·Gemini·GPT를 모두 쓸 수 있나요?

다음 두 방식이 있으며 서로 다릅니다.

- 공식 API(BYOK): 설정에서 OpenAI, Gemini 또는 Anthropic API 키를 연결하는 방식
- 실험적 CLI 로그인: `2_AI_LOGIN`에서 Claude 또는 Codex CLI 계정으로 로그인하는 비공개 베타 기능
- Gemini: 공급자 정책에 따라 앱에서는 공식 Gemini API(BYOK)로만 연결

Codex CLI 로그인은 일반 ChatGPT 웹 로그인과 같다고 보장되지 않습니다. Gemini CLI도 계정 종류와 현재 이용 자격에 따라 거절될 수 있습니다. 공급자 정책·요금·사용량 제한은 각 계정에 적용됩니다.

### AI에 로그인하지 않아도 되나요?

네. 로컬 녹음·영상·필기만 사용할 때는 AI 연결을 건너뛸 수 있습니다. 받아쓰기·AI 회의록을 만들려면 사용하려는 방식의 연결 상태와 인터넷을 확인하세요.

### AI 회의록만 실패했습니다.

원본이나 받아쓰기를 지우지 마세요. 인터넷, 로그인 만료, API 사용량을 확인한 뒤 오른쪽 아래 `작업함`에서 `회의록 다시 만들기`를 선택하세요.

## 녹음·영상·필기

### 음성만 녹음할 수 있나요?

네. `녹음 시작`에서 `카메라 영상 함께 녹화`를 끄면 됩니다. 칠판이나 회의실도 남기려면 이 옵션을 켭니다. 영상 모드에서도 함께 녹음된 음성으로 받아쓰기와 회의록을 만듭니다.

### 녹음하지 않고 필기만 할 수 있나요?

네. 홈에서 `필기만 시작`을 누르면 키보드 노트와 펜 필기를 사용할 수 있으며 녹음·AI 전송은 시작되지 않습니다.

### 앱이나 브라우저가 중간에 닫혔습니다.

앱을 다시 열고 `작업함`과 `라이브러리`를 먼저 확인하세요. 복구된 작업은 이어서 처리하거나 재시도할 수 있습니다. 확인이 끝날 때까지 원본 녹음·영상 파일을 삭제하지 마세요.

## 기존 파일 가져오기

### 어떤 파일을 가져올 수 있나요?

MP3, WAV, M4A, WEBM, OGG, FLAC, MP4 파일을 지원하며 최대 512MB입니다. 제목과 문서 형식이 잘못 연결되지 않도록 한 번에 파일 하나만 선택합니다. 일부 코덱은 ffmpeg가 필요할 수 있습니다.

### 파일을 선택했는데 아무 변화가 없습니다.

지원 형식·512MB 이하인지 확인하고 다시 선택하세요. 오류가 난 뒤에도 선택 창이 계속 처리 중으로 보이면 창을 닫고 다시 열어 한 파일만 선택하세요.

### 진행 상황과 완료 결과는 어디에 있나요?

진행·실패·재시도는 화면 오른쪽 아래 `작업함`, 완료된 회의와 원본 재생·내보내기는 `라이브러리`에서 확인합니다.

## 데이터와 개인정보

### 녹음과 필기는 어디에 저장되나요?

기본적으로 설치한 AI PRONOTE 폴더의 `data_v15`에 저장됩니다. 폴더를 이동하거나 삭제하기 전에는 앱을 종료하고 `data_v15`를 별도 저장소에 복사하세요. 구버전 데이터 폴더에 덮어쓰지 마세요.

### 완전히 삭제하려면 어떻게 하나요?

라이브러리에서 회의록을 지우면 실수 복구를 위해 휴지통과 녹음 원본이 남습니다. 모든 로컬 데이터를 없애려면 녹음과 작업을 먼저 끝낸 뒤 설정의 `이 설치본 데이터 영구 삭제`를 사용하세요. 이 기능은 브라우저 데이터, `data_v15` 작업 파일과 공식 API 키를 지우고 로그아웃하지만 Claude·Gemini·Codex CLI 로그인 및 온라인 계정 자체는 삭제하지 않습니다.

### 회의 내용을 외부 AI로 보내나요?

AI 회의록 기능을 사용할 때 선택한 외부 AI로 필요한 내용이 전송될 수 있습니다. 참석자에게 녹음·녹화와 AI 처리 사실을 알리고 동의를 받은 뒤 사용하세요. 회사 정책상 외부 전송이 금지된 회의는 AI 기능을 끄고 로컬 녹음·필기만 사용하세요. 생성 결과의 결정·수치·담당자는 원문과 대조해야 합니다.

## 오류 제보

다음 정보를 함께 보내면 확인이 빠릅니다.

- RC31, 운영체제 버전, Mac/Windows와 CPU 종류
- 수행한 흐름: 녹음 / 영상+음성 / 필기 / 파일 가져오기 / AI 회의록
- 기대한 결과와 실제 결과, 재현 순서, 발생 빈도
- 파일 형식·길이·크기(파일 내용은 제외)
- 민감정보를 가린 화면 캡처와 작업함의 오류 문구

먼저 `설정 · 어드민 → 안전한 진단정보 내보내기`에서 JSON을 저장하고 직접 확인한 뒤 전달할 수 있습니다. 이 파일에는 버전·환경·개수·상태만 들어가며 회의 내용·제목·파일명·녹음/영상·API 키·이메일·경로는 제외됩니다.

회의 원본, 회의 내용, 참석자 개인정보, API 키, 토큰, 비밀번호, 로그인 화면은 보내지 마세요. 자동 장애 전송 기능은 없으므로 공유하기 전 내용을 직접 확인해야 합니다.

## 현재 베타의 제한

- 코드 서명·공증, 자동 업데이트, 자동 장애 보고는 아직 제공하지 않습니다.
- Claude·Codex CLI 로그인은 실험 기능이며 공급자 정책이나 계정 자격에 따라 달라질 수 있습니다.
- Gemini CLI OAuth를 제3자 앱 연결에 사용하지 않습니다. Gemini는 유료 공식 API(BYOK)를 사용해야 합니다.
- Gemini·Codex의 로컬 로그인 파일은 실제 호출 자격을 보장하지 않습니다. 화면의 `로그인 정보 발견`은 첫 회의록 생성 전 미검증 상태이며, 계정 등급이나 공급자 클라이언트 정책에 따라 거절될 수 있습니다. 이 경우 공식 API 연결을 사용하세요.
- 대용량 파일, 긴 녹음, 화자 분리 정확도는 컴퓨터 성능·음질·모델에 따라 달라집니다.
- 개인정보·녹음 동의 문구는 법률 검토 전 초안입니다.
