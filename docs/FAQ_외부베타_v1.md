# AI PRONOTE 1.0.10 비공개 베타 FAQ

실제 회의 전에는 5분 이하의 비민감 자료로 먼저 시험하세요.

## 설치와 실행

### 지원 환경

- Windows 10/11 64비트와 Python 3.12 64비트
- iPad·iPhone·Android는 같은 Wi-Fi의 Windows 앱에 연결하는 PC 동반형
- 최신 Chrome 또는 Edge 권장
- Mac 독립 설치판은 이번 1.0.10 테스트에서 제공하지 않음

### Windows 보호 화면

이번 파일은 상용 코드서명 전 비공개 후보입니다. 다운로드 페이지의 파일명과 SHA-256을 먼저 확인하세요. Windows 보호 화면에서는 `추가 정보`를 누르고 `AI_PRONOTE_Desktop.exe`인지 확인한 뒤 초대받은 참가자만 실행하세요.

### 프로그램이 바로 열리지 않을 때

첫 실행은 전용 환경을 준비하므로 최대 45초 정도 걸릴 수 있습니다. 바탕화면의 `AI PRONOTE` 아이콘을 연속해서 누르지 마세요. 45초 뒤에도 열리지 않을 때만 한 번 다시 누릅니다.

## 계정과 AI

### 앱 로그인과 AI 연결의 차이

Google 앱 로그인은 사용자별 자료 구분과 향후 동기화를 위한 계정입니다. Claude·ChatGPT·Gemini 연결은 회의록과 AI 비서에 사용합니다. 서로 다른 계정입니다.

### 지원하는 AI

- Claude 구독 로그인
- ChatGPT/Codex 구독 로그인
- OpenAI·Gemini·Anthropic 공식 API 키(BYOK)
- Gemini CLI 로그인은 사용하지 않으며 공식 Gemini API로 연결

`설정 → AI 연결`에서 Claude와 ChatGPT 상태를 함께 확인하고 사용할 AI 하나를 선택합니다. API 키는 접힌 `개발자용 연결`에서 등록하며 Windows 자격 증명 관리자에 저장됩니다.

### AI 회의록만 실패했을 때

원본과 받아쓰기를 지우지 마세요. 인터넷과 선택한 AI의 로그인·사용량을 확인한 뒤 `작업 기록`에서 `AI 회의록 만들기` 또는 재시도를 누릅니다.

## 녹음·영상·노트

### 녹음은 자동으로 시작되나요?

아닙니다. 홈이나 왼쪽의 `회의 녹음`을 누르면 준비창만 열립니다. 사용자가 `녹음 시작`을 눌러야 시작됩니다.

### 영상도 녹화할 수 있나요?

준비창에서 카메라 영상 녹화를 켤 수 있습니다. 영상의 음성으로 받아쓰기와 회의록을 만듭니다.

### 노트만 사용할 수 있나요?

홈의 `내 노트` 또는 왼쪽의 `노트`를 누르세요. 녹음과 AI 전송 없이 키보드 텍스트와 펜·그림을 사용할 수 있습니다.

### 앱이나 브라우저가 닫혔을 때

다시 열고 `작업 기록`을 확인하세요. 복구된 작업은 이어서 처리하거나 재시도할 수 있습니다. 결과 확인 전에는 원본 파일을 삭제하지 마세요.

## 외부 파일

### 지원 형식과 크기

MP3, WAV, M4A, WEBM, OGG, FLAC, MP4 파일 하나를 최대 512MB까지 가져올 수 있습니다. 일부 코덱은 ffmpeg가 필요할 수 있습니다.

### 진행 상황과 결과 위치

현재 받아쓰기 화면과 `작업 기록`에서 단계, 진행률, 예상시간, 실패와 재시도를 확인합니다. 완료 항목에서는 원본, 받아쓰기, 회의록, 회의 메모와 전체 자료 ZIP을 저장할 수 있습니다.

### 전문용어 보정

`설정 → 받아쓰기 모델`의 전문용어 사전에 `잘못 들린 말=바른 말` 형식으로 한 줄씩 등록합니다. 수정 전 원문은 복구용으로 보존됩니다.

## 저장과 개인정보

Windows의 받아쓰기 원본·결과·작업 상태는 `%LOCALAPPDATA%\AI_PRONOTE\v1.5\data`에 저장됩니다. 브라우저에서 만든 회의·노트·필기는 앱의 브라우저 저장소에도 보존됩니다. 이동·삭제 전에는 작업을 끝내고 백업 또는 내보내기를 먼저 실행하세요.

외부 AI를 사용할 때 선택한 회의·노트 내용이 해당 제공자에게 전송될 수 있습니다. 녹음 동의와 조직 정책을 확인하고, 외부 전송이 금지된 회의는 AI 기능을 끄고 로컬 녹음·노트만 사용하세요.
