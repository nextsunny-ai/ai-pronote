## beta13 후보 감사 — 2026-09-20

### 증명됨

- Windows 후보 `1d562e7`: 관리형 버전별 설치, 공용 데이터 보존, 고정 바로가기, 시작 실패 복구, 기존 작업 재인식.
- 브라우저 핵심 흐름 66/66, Python 회귀 138/138, 실제 설치본 홈 화면과 버전 표시 육안 확인.
- 녹음 시작 전 마이크·카메라 선택, 입력 레벨, 카메라 미리보기를 제공하며 선택 장치 제약조건이 실제 녹음 시작까지 전달되는 자동검사를 통과했습니다.
- Windows·macOS 설치 환경을 의존성 잠금 파일과 동일한 Python 3.12 64비트로 고정해 하위 버전에서 설치가 중간 실패하는 위험을 차단했습니다.
- 노트를 사용자 폴더로 분류·이동·필터링하고 선택 폴더만 ZIP으로 백업한 뒤, 다른 데이터와 섞지 않고 폴더 구조까지 복원하는 회귀 시험을 통과했습니다.
- 노트북 실제 설치 후 beta13 서버 기동·바로가기 재실행·단일 8795 리스너 확인, 기존 작업 5건과 약 234MB의 공유 데이터 재인식.
- 녹음·영상 복구, 이어 녹음, 동시 완료 경합, 저장공간 부족, 장치 연결 종료에 대한 자동 회귀 시험.
- 노트 텍스트·펜·이미지·포스트잇·페이지·용지·분할 보기·내보내기·일괄 백업 흐름.
- 실제 설치본에서 포스트잇 기본 입력창이 동작하지 않는 결함을 발견해 앱 내부 입력창으로 교체하고, 정적 캐시 무효화 뒤 생성·저장·표시를 재검증함(`435d693`).
- 내장 브라우저가 지원하지 않는 필기 전체 삭제·페이지 삭제 확인창과 템플릿 오류 알림을 앱 내부 UI로 교체했다. 취소 시 원본 보존과 확인 후 삭제를 E2E로 검증함(`2e98810`).
- 홈·노트·라이브러리·설정 화면의 WCAG 2.1 AA 자동 감사를 추가했다. 낮은 보조문자·상태표시 명암을 수정해 심각·치명 자동 위반 0건을 검증함(`98d1dca`). 실제 NVDA·VoiceOver 수동 시험은 남아 있다.
- 앱 확인창과 포스트잇 편집창의 키보드 초점을 창 안에 유지하고, 닫은 뒤 원래 작업 위치로 복귀하도록 보강했다(`3de0328`, `833ff13`).
- 휴대폰 세로 390px·iPad 세로 768px·노트북 200% 확대 대응 640px에서 메뉴 진입·노트 표시·문서 가로 넘침 없음 자동 검증을 추가했다. 실제 iPad Pencil·VoiceOver 검증은 별도 게이트로 유지한다.
- 노트 제목·본문뿐 아니라 첨부 이미지의 원래 파일명도 통합 검색에서 찾도록 보강했다(`dd83c7a`). 손글씨 내용 OCR 검색은 아직 출시 게이트에 남아 있다.
