# 알려진 제한 v1

- unsigned 테스트본이라 Windows 경고가 나타날 수 있습니다. 경고를 우회해 외부 사용자에게 배포하지 않습니다.
- 코드 서명된 단일 실행 설치 프로그램, 무인 백그라운드 교체, 장애 보고 자동 전송은 아직 출시 승인 대상입니다. 첫 설정 뒤에는 새 버전 확인, 사용자가 선택하는 검증 다운로드·버전별 설치·재시작 전환·실패 시 이전 버전 복구를 제공합니다.
- 실제 공식 API 키에 의한 OpenAI/Gemini/Anthropic 종단 검증은 키 보유자가 직접 해야 합니다. Gemini 계정 로그인을 앱에서 대신 사용하는 방식은 제공하지 않습니다.
- Codex/Claude CLI 연결은 내부 실험 기능이며 공개판 기본 비활성입니다.
- AI 제공자별 연결 가능 여부는 `설정 → AI 연결`에 표시됩니다. Claude·ChatGPT/Codex와 Gemini 공식 API 경로의 실제 계정 종단 검증이 필요합니다.
- Windows RC51은 독립형 Windows 후보이며 휴대기기 클라우드 동기화가 포함되지 않습니다. 동일 제품의 네이티브 iPad 후보는 제작됐지만 대표 승인·실기기·운영 처리 서버 검증 전이므로 아직 배포하지 않습니다.
- QR·LAN companion은 내부 호환 시험 범위이며 정식 iPad 설치 방식이나 공개 지원 기능이 아닙니다.
- 반응형 iPad 화면과 기본 획·텍스트 입력은 확인했지만 실제 Safari의 Apple Pencil 압력·기울기·팜리젝션·VoiceOver는 물리 장비 최종 검증이 남아 있습니다.
- 대용량 파일, 긴 녹음, 화자 분리 정확도는 하드웨어·음질·모델에 좌우됩니다.
- 생성형 AI 결과는 부정확할 수 있으므로 중요한 결정·수치·담당자는 원문과 대조해야 합니다.
- 개인정보·녹음 동의 문구는 법률 검토 전 초안입니다.
