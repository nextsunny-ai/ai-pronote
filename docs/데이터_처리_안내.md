# AI PRONOTE 데이터 처리 안내

AI PRONOTE는 녹음·영상·받아쓰기·회의록·노트를 컴퓨터의 전용 저장소에 보관하고 앱 계정별로 구분합니다.

- AI 기능을 선택한 경우에만 회의 원문 또는 선택한 노트를 연결한 AI 서비스로 전송합니다.
- AI 서비스 연결 전 화면에서 전송 여부를 확인할 수 있습니다.
- 저장 위치와 사용량은 앱의 `설정 → 저장 위치`에서 확인합니다.
- 계정 전환 시 다른 계정의 자료는 표시하지 않습니다.
- 삭제와 복구는 앱의 휴지통 및 위험 작업 확인 절차를 따릅니다.

외부 테스트 기간에는 중요한 회의 전 짧은 시험 녹음과 결과 저장을 먼저 확인해 주세요.
