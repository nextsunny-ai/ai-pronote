# AI PRONOTE 개인정보·AI 데이터 처리 안내 내부 초안 v2

> 대표·법무 승인 전 내부 초안입니다. 특정 지역의 법률 자문이나 이용약관을 대신하지 않습니다.

## 제품이 실제로 처리하는 정보

AI PRONOTE는 사용자가 선택한 기능에 따라 녹음·영상, 받아쓰기, 노트, 첨부 이미지, 회의 정보와 AI 생성 결과를 처리합니다. 일반 녹음·영상·필기·기본 받아쓰기는 AI 계정 연결 없이 사용할 수 있습니다.

## 어디에서 처리되는가

- 녹음·영상·노트·기본 받아쓰기 결과는 사용자의 기기에 저장됩니다.
- AI 회의록이나 에이전트를 실행할 때만 사용자가 선택한 OpenAI·Gemini·Anthropic 제공자에게 필요한 내용을 보냅니다.
- 외부 전송 전에는 제공자와 전송 범위를 화면에 표시하고 사용자가 직접 실행합니다.
- 공식 API 키는 브라우저 저장소나 iPad에 저장하지 않습니다. Windows에서는 운영체제 자격 증명 저장소를 사용합니다.
- Claude·ChatGPT/Codex 계정 로그인은 내부 실험 기능이며 공개판의 기본 연결 방식이 아닙니다.

## 녹음 안내

AI PRONOTE는 사용자에게 특정 고지 문구나 동의 절차를 강제하지 않습니다. 녹음·영상 사용자는 자신의 회의 환경, 조직 정책과 적용 지역의 규칙을 확인해야 합니다. 제품 화면과 설명서는 기능의 데이터 흐름을 설명하며 법률 판단을 대신하지 않습니다.

## 보관·백업·삭제

- 회의와 노트는 사용자가 삭제하거나 제거 기능을 실행하기 전까지 기기에 유지됩니다.
- 업데이트와 일반 제거는 사용자 데이터를 프로그램 파일과 분리해 보존합니다.
- 노트는 JSON 또는 ZIP으로 백업하고 기존 노트를 덮어쓰지 않은 새 노트로 복원할 수 있습니다.
- `이 기기의 AI PRONOTE 데이터 영구 삭제`는 로컬 회의·노트·녹음과 공식 API 키를 제거하는 별도 기능입니다. 외부 AI 제공자 계정의 사본이나 CLI 로그인은 해당 제공자에서 별도로 관리해야 합니다.
- 중요한 회의는 원본과 내보낸 결과를 별도 저장장치나 사용자가 선택한 클라우드에 추가 보관하는 것을 권장합니다.

## 진단정보와 지원

안전한 진단정보 내보내기는 버전·운영환경·작업 개수·상태만 포함하며 회의 내용, 제목, 파일명, API 키와 로그인 정보는 제외합니다. 문제를 전달할 때도 원본 음성·영상이나 로그인 화면을 보내지 않도록 안내합니다.
