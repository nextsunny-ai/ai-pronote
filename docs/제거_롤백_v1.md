# 제거·롤백 v1

## v1.5 중지

열린 브라우저 창을 닫고 앱의 정상 종료 기능을 사용합니다. 처리 중 작업이 없는지 작업함에서 확인한 뒤 종료하십시오. 강제 종료는 상태 파일 손상 위험이 있어 최후 수단입니다.

## 데이터 보존 제거

Windows 배포 폴더의 `uninstall_windows.ps1`을 실행하십시오. 기본 제거는 바로가기와 프로그램 파일만 날짜가 붙은 `uninstalled` 보관 폴더로 이동합니다.

- 회의·녹음·노트 데이터는 `%LOCALAPPDATA%\AI_PRONOTE\v1.5\data`에 그대로 보존됩니다.
- Windows 자격 증명 관리자의 공식 AI API 키도 보존됩니다.
- AI PRONOTE가 만든 것으로 확인된 바로가기만 보관하며, 동명의 다른 바로가기는 건드리지 않습니다.
- `restoration-record.json`에 원래 위치·보관 위치·복원 방법을 남깁니다.

영구 삭제는 다른 단계입니다. 필요한 백업을 먼저 확인한 뒤 앱 설정의 `이 기기의 AI PRONOTE 데이터 영구 삭제`를 사용하십시오.

## v1.4/v1.3 롤백

이전 실행 파일과 데이터는 v1.5와 분리되어 있습니다. 백업된 바로가기의 대상·인수·작업 폴더를 기록값과 대조한 뒤 복원하고, 해당 버전의 health URL과 기존 회의 목록을 확인합니다. v1.5의 `data_v15`를 구버전 데이터 폴더에 덮어쓰지 마십시오.

## 완전 삭제

설정의 `이 기기의 AI PRONOTE 데이터 영구 삭제`는 진행 중 녹음·받아쓰기가 없을 때만 실행됩니다. 브라우저의 회의록·노트·녹음·휴지통·설정, 로컬 데이터 폴더의 업로드·결과·로그, Windows 자격 증명 관리자의 AI PRONOTE 공식 API 키를 삭제하고 로그아웃합니다. Claude·Gemini·Codex CLI 로그인과 온라인 계정 자체는 삭제하지 않으므로 해당 CLI 또는 공급자 페이지에서 별도로 처리해야 합니다.

삭제 중 일부 저장소나 API 키 제거가 실패하면 성공으로 표시하지 않고 남은 범위를 안내합니다. 이 경우 앱을 종료하고 백업 필요 여부를 확인한 뒤 다시 시도하십시오. 앱 코드 폴더 자체는 데이터 삭제가 성공한 뒤 별도로 제거합니다.
