## JavaScript 테스트 도구

`package.json`의 Playwright와 axe-core는 개발·자동검사 전용이며 배포 ZIP에 포함되지 않는다. npm 보안 API는 두 차례 모두 유지보수 응답(HTTP 503)을 반환했다. 독립적으로 OSV 공식 batch API에 lockfile의 npm 패키지 5개와 정확한 버전을 조회했으며 반환된 취약점은 0건이었다. 공개 배포 직전에는 npm 공식 감사도 다시 수행한다.
