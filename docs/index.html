Windows 비공개 베타

Python 3.10~3.12 64비트와 인터넷 연결이 필요합니다. FIRST_SETUP을 한 번 실행한 뒤 앱을 시작하세요.

Windows ZIP 다운로드SHA-256

처음 사용하는 순서

설치부터 첫 테스트까지 세 단계입니다.

01

준비

ZIP을 로컬 폴더에 풀고 FIRST_SETUP을 실행합니다. Python 설치 페이지가 열리면 설치 후 FIRST_SETUP을 다시 실행하세요.

02

AI 연결은 선택

AI 회의록이 필요하면 공식 API(BYOK) 또는 실험적 Claude·Gemini·Codex CLI 연결을 사용합니다. 로컬 녹음·필기만 쓸 때는 건너뜁니다.

03

짧게 시험

5분 이하 비민감 회의 또는 녹음 파일 하나로 작업함→라이브러리까지 확인합니다.

비공개 베타 안내
코드 서명 전 시험판이라 운영체제 경고가 나타날 수 있습니다. 참석자 동의를 받은 뒤 사용하고, 보안 정책상 외부 AI 전송이 불가능한 회의에서는 AI 회의록을 끄고 로컬 녹음·필기만 사용하세요. CLI 연결은 실험 기능이며 공급자 정책·계정 자격에 따라 제한될 수 있습니다.
