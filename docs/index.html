회의의 말과
생각을 한곳에.

음성 또는 영상으로 회의를 기록하고, 키보드와 펜으로 필기합니다. 받아쓰기·회의록·원본·노트를 하나의 회의 기록으로 관리하고 AI 에이전트로 후속 작업을 이어가세요.

Windows 외부 테스트사용설명서
음성 회의녹음과 필기를 동시에 저장
영상 회의칠판·회의실 영상과 음성 기록
필기녹음 없이 노트만 독립적으로 사용
AI 에이전트회의 맥락으로 정리와 후속 작업 수행

기록부터 실행까지

회의 기록 앱, 필기 앱, AI 도구로 나뉘던 업무를 하나의 흐름으로 연결합니다.

01 / RECORD

회의 녹음

음성만 기록하거나 카메라를 켜 칠판과 회의실 장면을 함께 남깁니다.

02 / NOTE

동시 필기

키보드와 펜으로 작성한 노트를 회의 원본과 같은 기록 안에 보관합니다.

03 / TRANSCRIBE

받아쓰기

회의 언어를 선택하고 녹음 또는 기존 파일을 검색 가능한 텍스트로 바꿉니다.

04 / AGENT

AI 에이전트

결정·할 일·후속 문서를 회의 원문과 사용자의 노트를 바탕으로 정리합니다.

AI 연결 없이 시작

현재 Windows 외부 테스트에서는 일반 녹음, 영상 녹화, 기본 받아쓰기와 필기를 계정 연결 없이 사용할 수 있습니다. Mac 버전은 최신 후보 검증 후 공개합니다.

필요할 때 AI 연결

AI 회의록과 에이전트 기능은 OpenAI·Gemini·Anthropic 공식 API(BYOK)로 연결합니다. 내부 베타에서는 Claude·ChatGPT/Codex 계정 로그인도 실험 기능으로 제공합니다.

다운로드

플랫폼별 검증 상태를 구분합니다. Windows Beta 13은 대표 최종 확인 뒤 공개하며 Mac은 최신 통합 후보 검증 후 공개합니다.

MACOS · 최신 후보 검증 중

Mac

최신 통합 후보의 설치·녹음·영상·복구와 서명 검증을 진행한 뒤 공개합니다. 배포 시 setup_mac.command와 공증 상태를 함께 안내합니다.

준비 중
WINDOWS 10 / 11 · BETA 13 최종 확인 중

Windows

v1.5.0-beta13.20260920.4는 설치·재실행·롤백과 자동 회귀검사를 통과했습니다. 공개 후에는 ZIP을 풀고 1_FIRST_SETUP.cmd를 한 번 실행하면 바탕화면 아이콘으로 시작할 수 있습니다.

최종 확인 중
iPad·휴대폰 사용 · 현재는 독립 설치 앱이 아닙니다. AI PRONOTE를 실행한 컴퓨터와 같은 Wi-Fi에 연결한 뒤 컴퓨터 화면의 모바일 연결 주소를 Safari 또는 Chrome에서 여세요.
외부 테스트 버전 · 코드 서명 전 프리뷰이므로 운영체제 보안 안내가 표시될 수 있습니다. 중요한 회의 전에 5분 시험 녹음으로 마이크·카메라·저장을 먼저 확인하세요.

설치부터 회의 운영, 필기, AI 연결과 문제 해결까지 필요한 부분만 골라 확인하세요.

자주 묻는 질문

설치와 AI 연결 전 가장 많이 확인하는 내용을 정리했습니다.

AI에 로그인하지 않아도 사용할 수 있나요?

네. 현재 Windows 외부 테스트에서는 일반 녹음, 영상 녹화, 기본 받아쓰기와 필기를 AI 연결 없이 사용할 수 있습니다. AI 회의록과 에이전트 기능이 필요할 때 AI를 연결하세요.

영상으로 녹화해도 회의록을 만들 수 있나요?

네. 영상과 함께 저장된 음성을 사용해 받아쓰기와 회의록을 생성할 수 있습니다.

Claude만 사용할 수 있나요?

아닙니다. OpenAI·Gemini·Anthropic 공식 API(BYOK)를 지원합니다. 내부 베타에서는 Claude·ChatGPT/Codex 계정 로그인도 실험 기능으로 제공합니다.

해외회의와 개발회의에도 사용할 수 있나요?

한국어와 영어 받아쓰기 언어를 선택할 수 있습니다. 제품명·사람 이름·기술 용어는 노트에 함께 기록하고 결과에서 원본과 대조하는 것이 좋습니다.

기존 녹음이나 영상도 처리할 수 있나요?

네. 파일 가져오기는 이미 저장된 녹음·영상으로 받아쓰기와 회의록을 만드는 부가기능입니다.
