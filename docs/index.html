동시 필기

키보드와 펜으로 작성한 노트를 회의 원본과 같은 기록 안에 보관합니다.

03 / TRANSCRIBE

받아쓰기

회의 언어를 선택하고 녹음 또는 기존 파일을 검색 가능한 텍스트로 바꿉니다.

04 / AGENT

AI 에이전트

결정·할 일·후속 문서를 회의 원문과 사용자의 노트를 바탕으로 정리합니다.

내 기록은 내 계정에

AI PRONOTE 계정은 녹음·노트·회의록을 사용자별로 구분합니다. 앱 계정과 AI 계정은 서로 다른 연결입니다.

원할 때 AI 계정 연동

현재 연결 가능한 Claude 또는 ChatGPT 중 하나를 선택하면 AI 회의록과 후속 작업을 사용할 수 있습니다. Gemini는 준비 중입니다.

다운로드

승인된 설치 파일만 제공합니다. 현재 Windows 후보를 최종 확인하고 있으며 Mac은 승인된 Windows 화면과 기능을 기준으로 제작합니다.

WINDOWS 10 / 11 · 최종 확인 중

Windows

설치·재실행·데이터 보존·녹음·받아쓰기·노트·반응형 화면을 확인하고 있습니다. 승인 전 후보 파일은 공개하지 않습니다.

MACOS · 준비 중

Mac

Windows 최종 승인 후 같은 기능과 화면을 기준으로 서명·권한·설치·녹음·카메라를 검증해 제공합니다.

iPad·휴대폰 · 현재 컴퓨터용 AI PRONOTE와 같은 Wi-Fi에서 모바일 연결 주소를 Safari 또는 Chrome으로 열어 사용합니다. 화면은 세로·가로와 작은 휴대폰 너비에 맞게 바뀝니다. 독립 설치 앱은 별도 검증 후 제공합니다.
데이터 보관 · 컴퓨터의 전용 저장소에 보관하며 앱 계정별로 자료를 구분합니다. AI 기능을 사용할 때만 선택한 AI 서비스로 필요한 내용을 전송합니다.

자주 묻는 질문

계정, AI 연결과 모바일 사용 전 자주 확인하는 내용입니다.

앱 계정과 AI 계정은 무엇이 다른가요?

앱 계정은 내 자료와 구독을 관리합니다. AI 계정은 현재 연결 가능한 Claude·ChatGPT 중 사용할 서비스 하나를 선택합니다.

영상으로 녹화해도 회의록을 만들 수 있나요?

네. 카메라 영상과 함께 저장된 음성으로 받아쓰기와 AI 회의록을 만들 수 있습니다.

Claude만 사용할 수 있나요?

아닙니다. 현재 Claude와 ChatGPT를 지원하며 둘 중 하나를 선택할 수 있습니다. Gemini는 준비 중입니다.

iPad나 휴대폰만으로 사용할 수 있나요?

현재 외부 테스트는 컴퓨터가 실행 중이어야 합니다. 독립 설치 앱은 별도 검증 후 제공합니다.

기존 녹음이나 영상도 처리할 수 있나요?

네. 파일 가져오기에서 받아쓰기만 하거나, 받아쓰기와 AI 회의록을 함께 만들 수 있습니다.
