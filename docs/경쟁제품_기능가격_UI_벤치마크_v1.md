# AI PRONOTE 경쟁 제품 기능·가격·UI 벤치마크

기준일: 2026-09-18  
목적: 출시 UI, 기능 우선순위, 메시지와 가격 가설을 정하기 위한 공식 자료 기반 비교

## 1. 경쟁 시장은 세 축으로 본다

| 경쟁 축 | 대표 제품 | 사용자가 해결하려는 일 |
|---|---|---|
| 회의 기록·전사 | PLAUD, Otter, Notta, Fireflies, Granola | 회의를 놓치지 않고 원문·요약·할 일을 남김 |
| 노트·필기 | Goodnotes, Notability, OneNote, Notion | 생각·자료·손필기를 구조화하고 다시 찾음 |
| 회의 후 AI 실행 | Notion Agent, Fireflies Personal Assistant·AI Skills, Otter AI Chat | 회의 내용을 질문하고 후속 문서·업무를 처리함 |

AI PRONOTE는 세 번째 앱을 더 추가하는 제품이 아니라, 이 세 흐름을 **회의 한 건** 안에서 연결하는 제품으로 정의한다.

## 3. 사용자 비용 구조

기존 사용자는 보통 아래를 따로 결제한다.

1. 회의 녹음·전사·요약 서비스
2. 필기·노트 서비스
3. 회의 자료를 질문하고 후속 작업을 만드는 AI 또는 업무 도구

공식 공개 가격을 단순 조합하면 개인 사용자의 대표 조합만으로도 다음 수준이다.

| 조합 예시 | 공개 가격 기준 |
|---|---|
| PLAUD Pro + Goodnotes Pro | 연 165,000원 + 연 $35.99, 하드웨어 가격 별도 |
| Fireflies Pro + Goodnotes Pro | 연 $120 + 연 $35.99, 고급 AI 크레딧 별도 |
| Otter Pro + Goodnotes Pro | 연 약 $100 + 연 $35.99 |
| Granola Business + Goodnotes Pro | 연 $168 + 연 $35.99 |

통화·지역·프로모션이 달라 직접 합산 가격으로 광고하지 않는다. 대신 **여러 도구의 구독과 자료 이동을 한 제품으로 줄인다**는 가치와, 포함 기능 범위를 명확히 비교한다.

## 4. AI PRONOTE의 검증 가능한 장점

1. **회의 원본과 사람의 생각이 함께 남는다.** 음성·영상·받아쓰기·키보드 노트·펜 필기를 회의 한 건에 묶는다.
2. **필기만으로도 독립 사용이 가능하다.** 녹음 앱에 노트를 덧붙인 구조가 아니라 노트 자체가 핵심 사용 흐름이다.
3. **AI는 선택 사항이다.** 녹음·영상·기본 받아쓰기·필기는 AI 연결 없이 시작하고, 필요한 순간에 AI를 연결한다.
4. **AI 제공자를 사용자가 선택한다.** Claude, ChatGPT/Codex, Gemini 연결 방식을 분리해 특정 서비스 종속을 줄인다.
5. **회의 후 실행까지 같은 맥락을 쓴다.** 에이전트가 회의록만 만드는 것이 아니라 회의 원문과 사용자의 노트를 바탕으로 질문·정리·후속 산출물을 돕는다.
6. **별도 하드웨어가 필요 없다.** 사용 중인 Mac·Windows 장치에서 시작할 수 있다.
7. **기존 녹음·영상도 같은 작업 흐름에 편입한다.** 과거 자료도 새 회의와 같은 라이브러리 구조로 관리한다.

## 5. 출시 UI 원칙

- 홈 화면의 첫 행동은 `회의 녹음`이며, `필기만 시작`은 같은 위계의 독립 행동으로 둔다.
- 기록 시작 전에 음성/영상, 언어, 입력 장치만 결정하게 하고 AI 연결은 강제하지 않는다.
- 회의 중 화면은 녹음 상태, 필기, 필요한 경우 AI 보조만 남긴다. 설정과 홍보 요소는 숨긴다.
- 결과 화면은 `회의록 / 받아쓰기 / 노트 / 원본 / AI 에이전트`를 명확한 탭으로 구성한다.
- 에이전트는 막연한 채팅창이 아니라 `결정 확인`, `할 일 정리`, `후속 메일`, `개발 이슈`, `보고서 초안`처럼 결과 행동을 제시한다.
- 문구는 사용자를 가르치는 말투보다 현재 상태와 다음 행동을 전문적으로 표시한다.
- 아이콘·카드·색상은 기능 구분에만 쓰고 장식용 이모지와 과도한 둥근 카드·홍보 문구는 사용하지 않는다.
- 다운로드 페이지는 제품 기능, 사용설명서, FAQ, 지원환경, 다운로드를 같은 정보 체계 안에 둔다.

## 6. 가격 가설

출시 전 가격은 확정하지 않고 다음 가설을 검증한다.

| 안 | 대상 | 구성 | 검증 포인트 |
|---|---|---|---|
| 로컬 기본 | 개인·프리랜서 | 녹음·영상·필기·기본 받아쓰기·라이브러리 | 무료 또는 1회 구매가 설치 장벽을 낮추는지 |
| Pro 통합 | 회의가 잦은 개인 | AI 회의록·에이전트·고급 내보내기·정확도 향상 | 월 9,900~14,900원 범위에서 세 앱 통합 가치가 전달되는지 |
| Team | 개발·기획·전문팀 | 공유·템플릿·권한·프로젝트별 에이전트 | 좌석당 가격과 관리 기능 요구 수준 |

BYOK 또는 사용자 계정 연결은 AI 비용을 낮출 수 있지만, 공급자 약관·계정 자격·사용량 비용을 별도로 명확히 안내해야 한다. 가격 경쟁력은 낮은 숫자만이 아니라 **중복 구독 제거, 자료 이동 감소, 회의 후 작업 시간 단축**으로 검증한다.
