# AI PRONOTE 노트 기능 경쟁 분석

- 작성일: 2026-09-18
- 목적: 회의 녹음·AI 회의록과 함께 쓰는 노트 기능의 출시 우선순위 결정
- 비교 대상: Goodnotes, Notability, Microsoft OneNote, Apple Notes

## 결론

시판 노트 앱의 공통 기본선은 `자동 저장 → 다시 열기 → 검색 → 여러 형식 내보내기 → 공유 → 백업·복구`다. AI PRONOTE의 차별점은 노트만 잘 쓰는 데 있지 않고, 노트·녹음·받아쓰기·AI 회의록을 한 회의 안에서 함께 보존하는 데 있다.

따라서 노트 기능은 다음 순서로 강화한다.

1. 데이터 보존: 자동 저장, 명시 저장, 실패 안내, 원본 백업과 다시 불러오기
2. 외부 전달: TXT, Markdown, HTML, PDF, PNG 텍스트 스냅샷, 운영체제 공유
3. 회의 결합: 노트와 녹음 시간 연결, 이어 녹음 구간을 같은 회의로 묶기
4. 대규모 관리: 폴더·태그·즐겨찾기·휴지통·묶음 내보내기
5. 고급 기능: 필기 OCR/검색, 동기화, 선택적 협업 링크

## 이번 반영

- PNG 텍스트 스냅샷 내보내기 추가
  - 사진이 제외됨을 메뉴에 명시
  - 안전한 캔버스 크기만 허용
  - 너무 긴 노트는 조용히 자르지 않고 PDF/HTML 사용 안내
- `.pronote.json` 백업 불러오기 추가
  - 기존 노트를 덮어쓰지 않고 새 노트 생성
  - 50개 초과 기존 노트도 삭제하지 않음
  - 중복 실행 방지, 진행 상태, 실패 롤백 적용
  - 스크립트·이벤트·외부 이미지 URL 제거 후 복구

## 다음 구현 우선순위

### P0 — 외부 베타 전

- 동일 회의의 여러 녹음 구간을 하나의 회의 카드·받아쓰기·회의록으로 병합
- 노트 JSON 내보내기 → 다시 불러오기 실제 Windows·Mac 수동 검증
- 사진 포함 노트의 HTML·JSON·PDF 보존 수동 검증
- 긴 노트·저장공간 부족·앱 재시작 복구 검증

### P1 — 출시 후보

- 여러 노트 선택 후 ZIP 백업과 일괄 PDF/HTML 내보내기
- 휴지통과 복원
- 폴더·태그·즐겨찾기, 최근 수정 정렬
- 회의 녹음 시간과 필기 위치 연결 및 해당 시점 재생
- Word 문서 내보내기

### P2 — 정식 출시 후

- 한국어·영어 손글씨 OCR과 통합 검색
- 기기간 선택 동기화와 충돌 복구
- 보기 전용/편집 가능 링크, 만료·권한·공유 중지
- 공동편집과 댓글

## 제품 원칙

- 내보내기는 원본을 삭제하거나 이동하지 않는다.
- 복구는 현재 노트를 덮어쓰지 않고 새 노트로 만든다.
- 일부 내용이 제외되거나 길이 제한이 있으면 실행 전에 용도를 명확히 표시한다.
- 공유는 사용자가 직접 누른 경우에만 실행한다.
- 회의 결과 자동 공유에는 개인 노트를 포함하지 않는다.
