## 검증 구성

- 패키지 서버와 전용 데이터 폴더 사용
- Chromium MediaRecorder에 640×360 합성 카메라와 440Hz 합성 마이크 입력
- 영상과 별도 음성을 동시에 3,605초 녹화
- 정지 후 IndexedDB 기록, 회의 메타데이터, Blob 재생 URL, 임시 복구본 정리를 검사

## 60분 실행 증거

- 화면과 회의 메타데이터 지속시간: 1시간 00분
- 변환 전 음성 WebM 요청 본문: 58,093,454바이트
- 저장된 영상 WebM: 58,094,426바이트
- 음성 지속시간: 3,605초
- 영상 지속시간: 3,606초
- 회의 기록: 1건, 녹음 ID 생성
- 음성·영상 Blob URL: 모두 생성 가능

## 판정

Windows 공개 설치본의 60분 영상+음성 연속 캡처와 장시간 데이터 생성은 통과했다. MP3 변환 실패 시 원본 WebM 보존 저장도 별도 재검증에서 통과했다. 이 결과는 합성 장치 기반이므로 물리 Mac 시험, Windows 잠금·절전 복귀, 실제 회의 장치별 장시간 시험을 대체하지 않는다.
