# AI PRONOTE RC22 Mac 외부 베타 검증

중요한 회의 전에 비민감한 5분 시험을 먼저 실행하세요. RC22는 검증된 직접 의존성 버전과 64비트 Mac 환경 검사를 사용하며, 마이크·카메라 연결에 성공한 뒤에만 녹음 화면을 엽니다.

## 설치

1. Mac ZIP을 완전히 풀고 `mac/1_FIRST_SETUP.command`를 Control-클릭해 `열기`를 선택합니다.
2. 설치가 끝나면 `mac/2_AI_LOGIN.command`에서 사용할 AI를 준비합니다.
3. `mac/3_START_AI_PRONOTE.command`를 실행해 홈 화면이 열리는지 확인합니다.
4. 오류가 나면 마지막 오류 문구와 Mac 모델·칩·macOS·Python 버전을 기록합니다.

## 5분 음성·필기

`음성만 녹음`에서 마이크 권한을 허용하고 5분간 말하며 필기를 남깁니다. 권한을 거부했을 때 녹음 화면으로 넘어가지 않는지도 확인합니다. 종료 후 받아쓰기→작업함→라이브러리→결과 재열기→녹음 재생을 확인하고, Claude 회의록의 결정사항·담당자·기한을 원문과 대조합니다. 앱을 종료했다 다시 열어 자료가 남는지 확인합니다.

## 카메라·칠판

`카메라 영상 + 음성`으로 칠판이나 종이를 2분 촬영합니다. 장치 연결 중 취소했을 때 카메라 표시가 꺼지고 녹음 화면으로 넘어가지 않아야 합니다. 정상 종료 뒤 영상과 별도 음성 원본이 모두 재생되고 음성에서 받아쓰기와 회의록이 생성되면 합격입니다.

## 60분

전원을 연결하고 비민감 내용으로 60분 녹음합니다. 15분·30분·45분에 필기를 남긴 뒤 녹음 길이와 누락, 필기, 받아쓰기, 원본 재생, 앱 재실행 후 재열기를 확인합니다. 카메라 모드라면 영상과 별도 음성 모두 확인합니다.
