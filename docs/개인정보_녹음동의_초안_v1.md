# 개인정보·녹음 동의 안내 초안 v1

> **법무 검토 전 내부 초안입니다. 외부 공개·약관 동의 문구로 사용하면 안 됩니다.**

AI PRONOTE는 회의 음성, 받아쓰기, 발언자 정보, 사용자가 입력한 노트 및 AI가 생성한 요약을 처리할 수 있습니다. 회의 주최자는 녹음 시작 전에 참석자에게 다음 사항을 알리고 명시적 동의를 받아야 합니다.

- 녹음 목적과 이용 범위
- AI 받아쓰기·요약 처리 여부와 사용 제공자
- 저장 위치, 보관 기간, 접근 가능한 사람
- 동의 철회 및 원본·파생 데이터 삭제 요청 방법

권장 고지 예시: “이 회의는 정확한 기록과 회의록 작성을 위해 녹음되며 AI 받아쓰기·요약에 사용됩니다. 결과와 원본은 [보관 위치]에 [기간] 동안 보관됩니다. 동의하지 않거나 중단을 원하시면 지금 말씀해 주세요.”

원칙: 필요한 최소 데이터만 처리하고, 민감 회의에는 외부 API 전송 전 별도 확인을 받으며, API 제공자의 보관·학습 정책을 사용자가 직접 확인하게 합니다. iPad에는 API 키를 저장하지 않고 PC companion에서 처리합니다. 로그·피드백을 공유할 때 음성, 이름, 키, 토큰, 회의 내용을 제거합니다.

## 현재 제품 동작과 정책 초안

- 로컬 처리 시 원본 음성·전사·필기·요약은 사용자 PC에 저장되며, 회의 기록은 사용자가 삭제할 때까지 유지됩니다.
- 외부 AI는 사용자가 제공자를 선택하고 전송 동의를 한 경우에만 필요한 회의 내용을 전송합니다. 공식 BYOK와 실험 CLI는 별도 경로이며 iPad에는 키·CLI 자격 증명을 저장하지 않습니다.
- 동의 철회는 이후 전송을 중단합니다. 이미 외부 제공자에게 전송된 데이터는 소급 회수되지 않을 수 있어 해당 제공자의 삭제·보관 정책을 확인해야 합니다.
- 진단 로그는 원문·키·토큰을 포함하지 않는 것을 원칙으로 하고 로컬에서 최대 30일 보관 후 정리하는 정책을 제안합니다. 이 기간과 자동 삭제 구현은 법무·제품 승인 전 확정되지 않았습니다.
- 라이브러리의 회의록 삭제는 실수 방지를 위해 휴지통으로 이동하고 녹음 원본을 보존합니다. 설정의 `이 설치본 데이터 영구 삭제`는 브라우저 저장소, 서버 작업 파일과 공식 API 키를 제거하지만 외부 CLI 로그인·온라인 계정·외부 제공자 측 사본은 별도 처리해야 합니다. 삭제 범위·복구 불가 고지·백업 처리 방식은 출시 전 법무 검토 항목입니다.
- 녹음 고지와 참석자 동의 확보 책임은 회의 주최자에게 있습니다. 지역별 통신비밀·개인정보 법률 차이를 법무가 확인해야 합니다.
