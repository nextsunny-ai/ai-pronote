# AI PRONOTE v1.5 RC17 출시 후보 안내

AI PRONOTE는 Mac·Windows에서 회의 음성 또는 카메라 영상+음성을 녹음하고, 기존 녹음·영상 파일 받아쓰기, AI 회의록, 원문, 개인 필기와 원본을 한 회의 단위로 관리하는 로컬 우선 앱입니다. 이 묶음은 **코드 서명 전 지정 사용자용 비공개 베타**이며 공개 배포본이 아닙니다.

## 빠른 시작

1. macOS 12 이상 또는 Windows 10/11(64비트), Python 3.10~3.12와 인터넷 연결을 준비합니다.
2. 압축을 쓰기 가능한 로컬 폴더에 완전히 풉니다. OneDrive/Google Drive 동기화 중인 폴더는 피하는 편이 안전합니다.
3. Mac은 `mac/1_FIRST_SETUP.command`, Windows는 `1_FIRST_SETUP.cmd`를 한 번 실행합니다.
4. Mac은 `mac/AI PRONOTE.app`, Windows는 `3_START_AI_PRONOTE.vbs`를 실행합니다.
5. 처음에는 짧은 비민감 음성으로 업로드→작업함→결과→다운로드를 확인합니다.

데이터는 기본적으로 앱 폴더의 `data_v15`에 저장됩니다. API 키는 OS 자격 증명 저장소를 사용하는 공식 BYOK 흐름만 권장합니다. iPad는 앱 파일을 설치하는 방식이 아니라 Windows companion에 HTTPS로 접속해 홈 화면에 추가하는 PWA 방식입니다.

## 정식 연동과 실험 기능

- 정식 공개 대상: OpenAI API, Gemini API, Anthropic API의 사용자 보유 키(BYOK).
- 내부 실험: `Codex CLI (실험)`, `Claude CLI (실험)`, `Gemini CLI (실험)`. 공개판에서는 feature flag로 숨깁니다.
- CLI 로그인은 소비자 계정의 일반 모델 로그인과 동일하다고 보장하지 않으며, 각 제공자 약관·배포 제한을 별도로 확인해야 합니다.

## 지원·제거·복구

오류 보고에는 앱 버전, Windows 버전, 재현 순서, 민감정보를 제거한 로그를 포함하십시오. 제거와 롤백은 `제거_롤백_v1.md`, 제한 사항은 `알려진_제한_v1.md`를 따릅니다. 녹음 전에는 반드시 참석자에게 녹음 및 AI 처리 사실을 알리고 동의를 받아야 합니다.

## 배포 상태

현재 상태는 unsigned 지정 사용자용 비공개 베타 후보입니다. 외부 공개, 코드 서명 구매, 유료 결제 연결과 법률 문구 확정은 대표님 별도 승인 전 금지합니다.
