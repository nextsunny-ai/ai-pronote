# AI PRONOTE 1.0.10 빠른 시작

## Windows 설치

1. `AI_PRONOTE_1.0.10_Windows_Private_Beta.zip`을 내려받아 새 폴더에 완전히 압축 해제합니다.
2. 압축을 푼 폴더에서 `1_FIRST_SETUP.cmd`를 두 번 누릅니다. 설치 완료 안내가 나올 때까지 창을 닫지 마세요.
3. 설치가 끝나면 바탕화면의 `AI PRONOTE` 노트+마이크 아이콘을 한 번 누릅니다.
4. 첫 실행은 전용 환경을 확인하므로 최대 45초 정도 걸릴 수 있습니다. 아이콘을 반복해서 누르지 마세요.
5. 로그인 화면에서 Google 로그인을 완료합니다. 로그인하지 않아도 이 기기의 로컬 노트와 녹음은 사용할 수 있습니다.

Windows 보호 화면이 나오면 `추가 정보`를 누르고 파일명이 `AI_PRONOTE_Desktop.exe`인지 확인한 뒤, 초대받은 테스트 참가자만 `실행`을 누르세요. 이 비공개 베타 실행 파일에는 아직 상용 코드서명이 없습니다.

## 내 노트

홈의 `내 노트` 또는 왼쪽의 `노트`를 누르면 빈 캔버스가 열립니다. 펜·텍스트·형광펜·지우개·올가미·포스트잇·도형·사진·여러 페이지·용지 설정·분할 보기를 사용할 수 있습니다. 휴대폰의 보조 기능은 `더보기`에 있습니다. 저장하면 날짜와 시간이 포함된 이름으로 `작업 기록`에 남습니다.

## 회의 녹음

1. 홈 또는 왼쪽 메뉴에서 `회의 녹음`을 누릅니다.
2. 음성만 녹음할지 카메라 영상도 함께 녹화할지 선택합니다.
3. 회의명과 참석자는 선택 입력입니다. 비워도 시작할 수 있습니다.
4. 사용자가 `녹음 시작`을 눌러야 녹음이 시작됩니다.
5. 회의 중 키보드 메모와 펜 필기를 함께 사용할 수 있습니다.
6. `정지 · 받아쓰기 시작`을 누르면 저장 중 표시가 나오며 반복 클릭은 막힙니다.
7. 진행률과 예상시간, 실패·재시도는 `작업 기록`에서 확인합니다.

## 외부 녹음·영상 받아쓰기

1. 왼쪽의 `받아쓰기`를 엽니다.
2. MP3, WAV, M4A, WEBM, OGG, FLAC 또는 MP4 파일 하나를 선택합니다. 최대 512MB입니다.
3. `받아쓰기만` 또는 `받아쓰기 + AI 회의록`을 선택합니다.
4. 업로드·받아쓰기·회의록 생성 상태는 현재 화면과 `작업 기록`에 표시됩니다.
5. 완료 후 원본, 받아쓰기, AI 회의록, 회의 메모와 전체 자료 ZIP을 저장할 수 있습니다.

## 회의록

`회의록`에서는 새 회의록을 직접 작성하거나 기존 회의록을 검색·불러오기·수정할 수 있습니다. AI가 만든 회의록도 같은 화면에서 수정하고 DOCX·PDF·MD·TXT 등 제공되는 형식으로 저장합니다.

## AI 연결과 AI 비서

- `설정 → AI 연결`에서 Claude와 ChatGPT 연결 상태를 함께 확인하고 실제 사용할 AI 하나를 선택합니다.
- Gemini는 접힌 `개발자용 연결`에서 공식 Gemini API 키로 연결합니다.
- 회의·노트를 외부 AI로 보낼 때는 전송 동의를 직접 켜야 합니다.
- AI 비서는 현재 회의, 받아쓰기, 회의 메모와 이전 대화를 전달하고 응답 시간과 전달된 맥락을 표시합니다.

## iPad·iPhone·Android

휴대기기판은 이번 비공개 베타에서 Windows PC 동반형입니다. PC 앱을 실행한 뒤 같은 Wi-Fi에서 앱이 표시하는 QR 또는 6자리 연결 코드를 사용합니다. Safari 또는 Chrome에서 열고 홈 화면에 추가할 수 있습니다. PC가 꺼지거나 다른 네트워크에 있으면 연결되지 않습니다.

## 문제 보고

문제 화면, 누른 메뉴, 발생 시각, 기기 종류를 기록하세요. 녹음 원본, 회의 내용, 로그인 정보, API 키와 토큰은 보내지 마세요.
