# AI PRONOTE 1.0 빠른 시작

## 1. 첫 실행

바탕화면의 `AI PRONOTE` 아이콘을 엽니다. 앱 계정으로 로그인하면 내 녹음·노트·회의록만 표시됩니다.

## 2. 회의 시작

홈에서 `녹음 시작`을 누르고 `음성 녹음` 또는 `카메라 영상`을 선택합니다. 마이크와 카메라 미리보기를 확인한 뒤 시작합니다.

## 3. 회의 종료

`종료`를 누르면 녹음이 저장되고 받아쓰기가 시작됩니다. 진행 상태는 `처리 현황`, 완료 결과는 `라이브러리`에서 확인합니다.

## 4. 결과 저장

라이브러리 카드에서 `받아쓰기 저장` 또는 `녹음 저장`을 바로 선택합니다. AI 회의록이 필요하면 연결 가능한 Claude 또는 ChatGPT 중 하나를 선택합니다.

## 5. 필기만 사용

홈에서 `필기만 시작`을 선택합니다. 작업막대에서 펜·지우개·형광펜·선택·이미지·포스트잇·용지를 사용할 수 있습니다.

## 6. iPad·휴대폰

컴퓨터와 같은 Wi-Fi에 연결하고 앱의 모바일 연결 주소를 Safari 또는 Chrome에서 엽니다. 현재 외부 테스트는 컴퓨터가 실행 중이어야 합니다.
