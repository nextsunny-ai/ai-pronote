# AI PRONOTE 1.0.10 빠른 시작

## Windows 설치

1. `AI_PRONOTE_1.0.10_Windows_Private_Beta.zip`을 내려받아 새 폴더에 압축을 풉니다.
2. 압축을 푼 폴더에서 `install_external_beta.ps1`을 마우스 오른쪽 버튼으로 눌러 PowerShell로 실행합니다.
3. 설치가 끝나면 바탕화면의 `AI PRONOTE` 노트+마이크 아이콘을 한 번 누릅니다.
4. 첫 실행은 전용 환경을 확인하므로 잠시 걸릴 수 있습니다. 창을 반복해서 누르지 마세요.
5. 로그인 화면에서 Google 로그인을 완료합니다. 다른 사용자의 자료는 표시되지 않아야 합니다.

Windows가 보호했다는 화면이 나오면 `추가 정보`에서 게시자와 파일명을 확인한 뒤 테스트 참여에 동의한 경우에만 실행하세요. 이 비공개 베타 실행 파일에는 아직 상용 코드서명이 없습니다.

## 새 노트

홈의 `내 노트`를 누르면 바로 빈 캔버스가 열립니다. 펜·텍스트·형광펜·지우개·색상·굵기는 상단에 있고, 페이지·용지·사진·분할·내보내기는 둘째 줄 또는 휴대폰의 `더보기`에 있습니다. 저장하면 날짜와 시간이 포함된 이름으로 내 노트와 작업 기록에 남습니다.

## 회의 녹음

1. 홈 또는 왼쪽 메뉴에서 `회의 녹음`을 누릅니다.
2. 음성 또는 카메라 영상을 선택하고 마이크·카메라 상태를 확인합니다.
3. 사용자가 `녹음 시작`을 눌러야 녹음이 시작됩니다.
4. `종료`를 누르면 즉시 `저장 중` 표시가 나오며, 반복 클릭은 막힙니다.
5. 받아쓰기와 회의록 진행률은 `작업 기록`에서 확인합니다.

## 외부 녹음·영상 받아쓰기

왼쪽 메뉴의 `받아쓰기`를 열고 녹음 또는 영상 파일을 선택합니다. 업로드·받아쓰기·회의록 생성 상태가 작업 기록에 표시됩니다. 완료 뒤 원본 오디오·영상, 받아쓰기, AI 회의록, 회의 메모와 전체 자료 ZIP을 저장할 수 있습니다.

## 결과 확인

- `회의록`: 새 회의록 작성, 기존 회의록 불러오기·수정·저장
- `작업 기록`: 날짜·프로젝트·길이·상태별 검색, 미완료 받아쓰기·회의록 재실행
- `AI 비서`: 선택한 AI에 현재 회의·받아쓰기·회의 메모·이전 대화를 전달하고 응답 시간과 전달된 맥락을 표시

## iPad·휴대폰

PC와 같은 Wi-Fi에서 PC의 `iPad·휴대폰 연결`에 표시되는 QR 또는 주소를 사용합니다. 현재 비공개 베타의 휴대기기판은 PC 동반형이므로 PC 앱이 실행 중이어야 합니다. 자세한 내용은 `휴대폰_iPad_사용가이드.md`를 확인하세요.

## 테스트 중 문제 보고

문제 화면, 누른 메뉴, 발생 시각, 기기 종류를 기록하세요. 녹음 원본과 회의 내용은 동의 없이 보내지 마세요.
