# AI PRONOTE RC18 Mac 외부 베타 검증

회의 내용이 없는 5분 시험을 먼저 하고, 성공한 뒤 실제 회의에 사용해 주세요. 처음부터 중요한 회의 하나만 맡기지 마세요.

## 설치 전 기록

- Mac 모델·칩: Apple Silicon(M1/M2/M3/M4 등) 또는 Intel
- macOS 버전:
- 저장공간 여유:
- 사용할 브라우저: Chrome 권장

## 1. 설치

1. 다운로드 페이지에서 Mac ZIP을 받아 완전히 압축 해제합니다.
2. `mac/1_FIRST_SETUP.command`를 Control-클릭해 `열기`를 선택합니다.
3. 완료 문구가 나타나면 `mac/2_AI_LOGIN.command`를 실행합니다. Claude 로그인을 쓸 경우 Claude 상태가 준비됐는지 확인합니다.
4. `mac/3_START_AI_PRONOTE.command`를 실행합니다.

합격: 설치가 종료 코드 없이 끝나고 AI PRONOTE 홈 화면이 열림.

## 2. 5분 안전 시험

1. `음성만 녹음`을 선택하고 마이크 권한을 허용합니다.
2. 5분 동안 말하면서 중간에 필기를 작성합니다.
3. 녹음을 끝내고 받아쓰기 완료를 기다립니다.
4. 작업함→라이브러리→결과를 열어 원문·필기·녹음 재생을 확인합니다.
5. Claude 회의록을 생성해 결정사항·담당자·기한이 원문과 맞는지 확인합니다.
6. 앱을 종료했다 다시 열어 같은 회의를 재확인합니다.

합격: 녹음·원문·필기·회의록이 하나의 회의로 남고 재시작 후 다시 열림.

## 3. 카메라·칠판 시험

1. `카메라 영상 + 음성`을 선택하고 카메라·마이크 권한을 허용합니다.
2. 칠판 또는 종이를 2분 촬영하며 말합니다.
3. 종료 후 영상과 별도 음성 녹음이 모두 재생되는지 확인합니다.
4. 받아쓰기와 AI 회의록에 말한 내용이 포함됐는지 확인합니다.

합격: 영상·음성·받아쓰기 중 하나도 빠지지 않음.

## 4. 장시간 시험

전원 어댑터를 연결하고 화면 잠금·절전 시간을 확인한 뒤 비민감 내용으로 60분 녹음합니다. 15분·30분·45분 시점에 필기를 한 줄씩 남기고, 종료 후 작업함과 라이브러리에서 다음을 확인합니다.

- 녹음 길이가 약 60분인지
- 필기 세 줄이 남아 있는지
- 받아쓰기가 완료되는지
- 종료·재실행 후 결과와 원본을 다시 열 수 있는지
- 저장공간이 비정상적으로 계속 증가하지 않는지

## 5. 문제가 생기면

원본과 `data_v15` 폴더를 삭제하지 마세요. 회의 내용·로그인 정보는 보내지 말고 아래만 전달해 주세요.

- RC18, Mac 모델·칩·macOS 버전
- 음성 / 카메라 / 필기 / 파일 가져오기 중 어느 흐름인지
- 발생 시점과 화면에 나온 오류 문구
- 재현 순서와 발생 빈도
- 파일 형식·길이·크기

Claude·Codex·Gemini CLI 로그인은 실험 기능입니다. `로그인 정보 발견`은 실제 호출 성공을 뜻하지 않습니다. Gemini CLI가 계정 정책으로 거절되면 공식 Gemini API 연결을 사용하세요.
