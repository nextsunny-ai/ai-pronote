# AI PRONOTE Mac 첫 사용 체크리스트

중요한 회의 전에 5분짜리 시험을 먼저 해주세요.

**AI 연결 없이 바로 시작할 수 있습니다.** 녹음·영상·받아쓰기·필기는 그대로 사용할 수 있습니다. AI 회의록, 받아쓰기 정확도 향상, 에이전트 기능이 필요할 때 AI를 연결하세요.

## 처음 설치

- [ ] ZIP 파일을 완전히 풀었습니다.
- [ ] `1_FIRST_SETUP.command`를 실행했습니다.
- [ ] AI 기능이 필요하면 Claude·ChatGPT 로그인 또는 Gemini API 키 연결을 완료했습니다.
- [ ] `3_START_AI_PRONOTE.command`를 실행했습니다.
- [ ] Chrome에서 마이크와 카메라 사용을 허용했습니다.

## 5분 시험

- [ ] 음성만 녹음하고 종료한 뒤 녹음이 재생됩니다.
- [ ] 받아쓰기와 AI 회의록이 만들어집니다.
- [ ] 카메라를 켜면 영상과 음성이 모두 저장됩니다.
- [ ] 필기만 작성한 뒤 앱을 다시 열어도 내용이 남아 있습니다.
- [ ] 기존 녹음 파일도 가져와서 회의록을 만들 수 있습니다.

## 문제가 생기면

- 원본 녹음이나 영상은 삭제하지 마세요.
- 앱 설정에서 `안전한 진단정보 내보내기`를 실행하세요.
- 회의 내용, API 키, 비밀번호는 다른 사람에게 보내지 마세요.
