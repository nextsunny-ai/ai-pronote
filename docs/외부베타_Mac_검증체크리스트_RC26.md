# AI PRONOTE RC26 Mac 외부 베타 검증

중요한 회의 전에 비민감한 5분 시험을 먼저 실행하세요. 실패하면 원본과 `data_v15`를 삭제하지 마세요.

## 설치

- [ ] ZIP을 완전히 푼 뒤 `1_FIRST_SETUP.command` 실행
- [ ] `2_AI_LOGIN.command`에서 사용할 AI 로그인
- [ ] `3_START_AI_PRONOTE.command` 실행 후 첫 화면 확인
- [ ] Chrome에서 마이크·카메라 권한을 직접 허용

## 필수 5분 시험

- [ ] 음성만 5분 녹음 → 정지 → 라이브러리 녹음 재생
- [ ] 받아쓰기 완료 → 회의록 생성 → 앱 재실행 후 다시 열기
- [ ] 카메라 영상+음성 5분 → 영상과 별도 음성 모두 재생
- [ ] 기존 녹음 파일 가져오기 → 받아쓰기 → AI 회의록
- [ ] 필기만 시작 → 저장 → 앱 재실행 후 복원

## 장시간 시험

- [ ] 전원 연결 상태에서 60분 음성 녹음
- [ ] 화면 잠금·절전 후 복귀했을 때 녹음과 타이머 상태 확인
- [ ] 저장공간 1GB 이상 확보 후 영상 녹화
- [ ] 마이크를 분리했을 때 현재 녹음이 자동 저장되는지 확인

## 복구·오류 제보

- 빨간색 `녹음 긴급 복구가 필요합니다` 패널이 나타나면 표시된 파일을 모두 다시 다운로드합니다.
- 다운로드 폴더에서 실제 파일 크기와 재생을 확인하기 전에는 앱 창을 닫지 않습니다.
- 오류가 나면 `설정 · 어드민 → 안전한 진단정보 내보내기`로 JSON을 저장하고, 내용을 직접 확인한 뒤 전달합니다.
- 진단 JSON에는 버전·환경·개수·상태만 들어가며 회의 내용·제목·파일명·녹음/영상·API 키·이메일·경로는 제외됩니다.
- 별도 제보에는 RC26, Mac 모델·칩, macOS, Python 버전, 발생 단계, 오류 문구, 재현 순서, 파일 길이·크기만 포함합니다. 회의 내용과 로그인 정보는 보내지 않습니다.
