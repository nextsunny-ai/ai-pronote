# 지원 환경 v1

| 구분 | 내부 테스트 기준 | 비고 |
|---|---|---|
| Mac | macOS 12 이상, Apple Silicon·Intel | Python 3.10~3.12, 코드 서명 전 베타 |
| Windows | Windows 10/11 64비트 | Python 3.10~3.12 64비트, 코드 서명 전 베타 |
| 브라우저 | 최신 Edge/Chrome 권장 | localhost 사용 |
| iPad | 최신 iPadOS Safari | HTTPS, 동일 Wi-Fi, PC companion 필요 |
| 입력 | MP3/WAV/M4A/WEBM/OGG/FLAC/MP4, 최대 512MB | 코덱에 따라 ffmpeg가 필요할 수 있음 |
| 저장공간 | 최소 5GB 여유 권장 | 모델·원본 음성에 따라 증가 |
| 네트워크 | localhost 기본 | iPad 모드는 명시적으로 켤 때만 LAN 노출 |

Apple Pencil, 손바닥 거부, VoiceOver는 실제 iPad 검증 전까지 지원 확정이 아닙니다. Linux, 다중 사용자 서버, 무인 인터넷 공개는 지원하지 않습니다. Mac은 실제 외부 Mac 장비 검증과 코드 서명·공증이 남아 있으므로 RC28에서는 비공개 베타 지원입니다.
