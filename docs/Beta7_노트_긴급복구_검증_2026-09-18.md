# Beta7 노트 긴급 복구 검증

검증일: 2026-09-18  
대상 버전: `v1.5.0-beta7.20260918`

## 검증 범위

브라우저 저장소 쓰기가 실패하는 조건에서 다음 동작을 확인했다.

1. 입력 중인 노트 본문과 편집 화면을 유지한다.
2. 저장 상태를 `저장 실패 · 복구본 필요`로 표시한다.
3. 사용자가 명시적으로 누를 수 있는 `긴급 복구본 다운로드`를 표시한다.
4. 내려받은 파일이 `ai-pronote-note` 형식의 가져오기 호환 JSON이며 제목과 정제된 HTML 본문을 포함한다.
5. 이후 저장이 성공하면 긴급 복구 안내와 임시 Blob URL을 정리한다.
