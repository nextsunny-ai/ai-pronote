# AI PRONOTE 1.0.10 상황별 사용 가이드

## 1. 일반 회의 — 음성만

왼쪽 `회의 녹음`을 누르면 새 회의 준비창이 열립니다. `음성 녹음`을 선택하고 `녹음 시작`을 눌러야 녹음이 시작됩니다. 회의명과 참석자는 선택 입력이므로 비워도 됩니다.

## 2. 칠판·회의실까지 남기기 — 영상+음성

`회의 녹음` 준비창에서 `영상 녹화`를 선택하고 카메라와 마이크 미리보기를 확인한 뒤 `녹음 시작`을 누릅니다. 영상은 이 기기에 저장되고, 함께 녹음된 음성으로 받아쓰기와 회의록을 만들 수 있습니다.

## 3. 녹음 없이 필기만

홈의 `내 노트` 또는 왼쪽의 `노트`를 누릅니다. 키보드 입력과 펜·형광펜·지우개·도형·사진·포스트잇을 한 캔버스에서 사용할 수 있습니다. 녹음이나 외부 AI 전송은 자동으로 시작되지 않습니다.

## 4. 기존 녹음·영상 파일

왼쪽 `받아쓰기`를 열고 `외부 녹음·영상 파일 가져오기`를 누른 뒤 MP3, WAV, M4A, WEBM, OGG, FLAC 또는 MP4 파일 하나를 고릅니다. 최대 크기는 512MB입니다. `받아쓰기만` 또는 `받아쓰기 + AI 회의록`을 선택합니다. 진행률과 예상 시간은 받아쓰기 화면과 `작업 기록`에서 확인하고, 완료된 원본·받아쓰기·회의록·회의 메모는 `작업 기록`에서 다시 열거나 내려받습니다.

## 5. AI 선택

왼쪽 아래 `설정`의 `AI 연결`에서 Claude와 ChatGPT 계정의 연결 상태를 각각 확인하고, 실제 사용할 AI 한 개를 선택합니다. Gemini는 공식 API 키를 사용하는 개발자용 연결만 지원하며 구독 계정 로그인은 준비 중입니다. 회의·노트를 외부 AI로 보낼 때는 `외부 전송 허용`을 켭니다.

## 6. 회의록 다시 만들기

받아쓰기는 끝났지만 AI 회의록이 만들어지지 않았다면 인터넷 연결, 선택한 AI와 외부 전송 허용 상태를 확인합니다. `작업 기록`에서 해당 회의를 열어 `AI 회의록 만들기`를 다시 실행합니다.

## 7. 파일을 잘못 선택했을 때

파일 선택창에서 `취소`하면 받아쓰기를 시작하지 않습니다. 작업을 이미 시작했다면 `작업 기록`에서 해당 항목의 더보기 메뉴를 열어 휴지통으로 이동합니다. 영구 삭제는 휴지통에서 다시 확인한 뒤 실행합니다.

## 8. 개인정보가 중요한 회의

녹음·녹화에 적용되는 지역별 법규와 조직 정책을 먼저 확인합니다. 외부 AI 전송이 허용되지 않는 회의에서는 설정의 외부 전송 허용을 끄고 로컬 녹음·필기·받아쓰기만 사용합니다.
