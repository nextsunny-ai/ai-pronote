# AI PRONOTE 1.0 상황별 사용 가이드

## 1. 일반 회의 — 음성만

왼쪽 `회의 녹음`을 누르면 음성 녹음이 바로 시작됩니다. 필요할 때만 AI를 연결하며, 가장 가볍고 긴 회의에 적합합니다.

## 2. 칠판·회의실까지 남기기 — 영상+음성

홈의 `회의 녹음` 카드에서 `영상 녹화`를 선택하고 카메라가 칠판을 향하는지 확인한 뒤 시작합니다. 영상은 이 기기에 저장되고, 함께 녹음된 음성으로 받아쓰기와 회의록을 만듭니다.

## 3. 녹음 없이 필기만

홈의 `새 노트` 또는 왼쪽의 `노트`를 누릅니다. 키보드 노트와 펜·형광펜·지우개·도형 필기를 사용할 수 있으며 녹음이나 AI 전송은 시작되지 않습니다. `메뉴 숨기기`로 작성 영역을 전체 화면으로 넓힐 수 있습니다.

## 4. 예전에 녹음한 파일

홈의 `파일 가져오기`를 누르고 MP3, WAV, M4A, WEBM, OGG, FLAC 또는 MP4 파일 하나를 고릅니다. 최대 크기는 512MB입니다. `받아쓰기만` 또는 `받아쓰기 + AI 회의록`을 선택하고 제목·참석자를 확인합니다. 진행은 상단의 `처리 중`, 완료 결과는 `회의 기록`에서 확인합니다.

파일 가져오기는 기존 녹음·영상으로 회의록을 만드는 부가기능이며, 기본 흐름은 앱에서 바로 회의를 녹음하는 것입니다.

## 5. AI 선택

`설정 → AI 계정`에서 앱이 연결 가능 상태로 표시한 Claude·ChatGPT·Gemini 중 한 개를 선택합니다. 두 제공자가 동시에 활성화되지는 않습니다. 일반 사용자는 API 키를 입력할 필요가 없으며, 개발자 방식은 접힌 `개발자용 연결`에서 별도로 설정합니다.

## 6. 회의록 다시 만들기

받아쓰기는 끝났지만 AI 정리만 실패했다면 인터넷 연결과 선택한 AI 계정의 연결·사용량을 확인한 뒤 `회의 기록`의 해당 항목에서 `AI 회의록 만들기`를 누릅니다.

## 7. 파일을 잘못 선택했을 때

문서 형식 선택 창에서 `취소`하면 받아쓰기를 시작하지 않습니다. 가져온 원본은 `회의 기록`에 보관됩니다. 민감 파일을 잘못 골랐다면 해당 항목의 더보기 메뉴에서 휴지통으로 이동하세요. 영구 삭제는 `회의 기록 → 휴지통`에서 다시 확인한 뒤 실행합니다.

## 8. 개인정보가 중요한 회의

녹음·녹화에 적용되는 지역별 법규와 조직 정책을 확인합니다. 회사 정책상 외부 AI 전송이 허용되지 않으면 AI 회의록을 끄고 로컬 녹음·필기만 사용합니다.
